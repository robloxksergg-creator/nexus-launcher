# NEXUS Testers 1.0.12 — Windows beta

Отдельная тестовая раздача. Обычная лента NEXUS и кнопка скачивания на сайте не переключаются на эту версию.

**Для установки скачайте NEXUS-Testers-Setup.exe.** Он скачает полный лаунчер и проверит подписанный манифест и файлы. Установка выполняется в отдельную папку; сессия beta-копии отделена от основной.

- Отдельная beta-лента автообновления с проверкой подписи, версии, хешей и состава пакета.
- Ограниченные повторы загрузки, проверка докачки и понятные сообщения об ошибках.
- Новый интерфейс заявок создателей и read-only каталог сообщества; серверная активация нового API выполняется отдельно.
- Включаемые обезличенные автоотчёты в очередь поддержки; доставка ботом пока не подтверждена.
- Выбранная роль создателя не выдаёт знак верификации.

Проверки: 2526 Python-тестов PASS, 19 пропущены; отдельный UI-тест PASS; Rust core 26 PASS и transport 8 PASS. Сверены 5540 файлов. Выполнены настоящая установка и обновление 1.0.11 → 1.0.12 на Windows runner; контрольный файл данных сохранён.

Это не подтверждение отсутствия всех ошибок. Реальные игровые сессии, VPN и сети тестеров требуют ручной проверки. Содержимое GearMorph не заменялось, реальные платежи и выдача новых платных/приватных пакетов не подключены. EXE без Authenticode-подписи Windows. Подробности и шаблон отчёта — в TESTER-INSTRUCTIONS.md.
