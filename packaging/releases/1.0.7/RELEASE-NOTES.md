# NEXUS Launcher 1.0.7 — Download Reliability Beta

Это бета-версия. Сообщайте об ошибках: версия NEXUS, ОС, действие, текст ошибки и диагностический журнал без паролей, кодов и токенов. Контакт: teentitans645@gmail.com.

## Изменения

- Ограниченные параллельные загрузки: до трёх задач в планировщике, до двух задач на один исходный host.
- Обработка обрывов собственных ZIP-загрузок: ограниченные повторы и проверка Range; обязательная проверка размера, подписи и хешей сохранена.
- Ограничены ожидания HTTP при установке Minecraft/Java. Проверка TLS не отключается.
- Отдельная проверка источников загрузки и понятные сообщения с host и причиной отказа.
- Улучшена видимость прогресса: байты и шаги подготовки отображаются отдельно, загрузки открываются при старте операции.
- Новый NEXUS-Setup.exe 1.0.7 с исправленным отображением прогресса. Проверена полная установка подписанного пакета.

## Установка и обновление

- Windows x64: скачайте NEXUS-Setup.exe. Существующие managed-установки получают 1.0.7 через подписанный NEXUS update feed после его активации. Переход 1.0.6 → 1.0.7 проверен на отдельных реальных Windows-процессах с синтетическими пользовательскими данными.
- Linux x64: полный tar.gz-пакет, базовая среда Ubuntu 24.04. Обновление вручную; сохраните пользовательские данные. Поддержка всех дистрибутивов, musl и ARM не заявляется.
- macOS Apple Silicon: полный ZIP приложения, macOS 15+. Обновление вручную. Intel Mac не входит в эту сборку.

## Проверки и ограничения

- Все три сборки и новый Setup собраны из коммита 59373a53f7675dcc5d1088b4f6e71769eac5fbd6.
- Полный native-аудит: https://github.com/robloxksergg-creator/nexus-launcher/actions/runs/41837410650
- Установка и обновление Windows: https://github.com/robloxksergg-creator/nexus-launcher/actions/runs/41890322345
- Подпись NEXUS update manifest не является Authenticode. EXE не имеет подписи издателя Windows; Smart App Control может блокировать новый файл. Вердикт для старой версии не гарантирует пропуск новой.
- macOS bundle имеет ad-hoc integrity signature, не Apple Developer ID и не notarization.
- Сеть тестера, скорость загрузки без VPN и реальный запуск Minecraft этой приёмкой не подтверждены. Случайные зеркала не добавлялись.
- Исправлена отсутствовавшая серверная таблица игровых билетов; успешный вход тестера ещё не подтверждён. Игровая статистика Gearmorph ещё не подключена.
- NEXUS C₂ не запускался и не разрешён этим релизом.
