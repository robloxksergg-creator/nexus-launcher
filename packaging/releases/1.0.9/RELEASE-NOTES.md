# NEXUS Launcher 1.0.9 — Windows Installer Path Fix Beta

Исправление для Windows. Linux и macOS остаются на проверенном выпуске 1.0.8 и своих подписанных лентах.

- Сокращены глубокие пути лицензионных файлов Qt/Chromium; все 1 999 исходных текстов и их происхождение сохранены. Обычные папки на рабочем столе и в профиле пользователя больше не требуют установки в корень диска.
- По умолчанию предлагается отдельная папка NEXUS Launcher рядом с EXE. Выбор папки используется точно, без повторного добавления NEXUS Launcher.
- При отказе в записи можно подтвердить запрос Windows на создание новой папки. Отдельный нативный помощник создаёт только новую папку и выдаёт исходному пользователю права записи. Существующие папки, сетевые пути и переходы через reparse points не используются для такого запроса.
- Установщик Python, скачивание, обновления и Minecraft не получают права администратора. Помощник не скачивает пакеты и не запускает игру. Реестр и настройки защиты Windows не меняются.

Для первой установки скачайте новый NEXUS-Setup.exe. Выберите новую пустую папку. Старые незавершённые установки и пользовательские данные не удаляются и не перезаписываются автоматически. Для уже работающей managed-установки доступно обычное подписанное обновление приложения.

Это бета-тест. EXE не имеет подписи Authenticode: UAC не снимает блокировку Smart App Control. Не отключайте защиту Windows. Запрос UAC с реальным подтверждением пользователем не автоматизировался; проверены вызов/отмена на mock API, создание папки нативным помощником, установка и обновление на Windows CI. Запуск Minecraft и реального аккаунта не входит в эти проверки.
