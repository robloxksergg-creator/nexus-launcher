# NEXUS 1.0.8 — обновления платформ

Windows managed: существующий подписанный GitHub-feed сохраняется. Запускайте установленный NEXUS.exe; новая версия проверяется и применяется перед запуском. Старые legacy-ветки с другими ключами этим механизмом не мигрируются.

Linux x64 и macOS Apple Silicon: для версии 1.0.7 и старше потребуется один раз установить полный пакет 1.0.8. В старых бинарниках нет нового механизма; обновить их автоматически задним числом нельзя. После первого готового окна лаунчер в фоне получает подписанный манифест именно установленной версии и сверяет все файлы. Только затем создаётся управляемая копия. Если сеть недоступна или проверка не пройдена, исходная версия остаётся доступной; подготовка повторяется при следующем запуске.

Сохраняйте имена папки NEXUS-Linux-x64 и приложения NEXUS Launcher.app, не изменяйте их внутренние файлы. Хранилище обновлений рассчитано на обычный локальный пользовательский каталог без симлинков в его пути. Root, sudo и права администратора не нужны.

После успешной подготовки проверка обновлений выполняется при старте. Каждый OS/CPU имеет отдельный подписанный манифест. Новая папка проверяется до выполнения; переключение требует ответа настоящего дочернего процесса по приватным наследуемым каналам после готовности интерфейса. При неопределённом состоянии новый запуск/переключение блокируются, а не повторяются вслепую.

Данные находятся вне приложения:
- Linux: $XDG_DATA_HOME/nexus-launcher, по умолчанию ~/.local/share/nexus-launcher.
- macOS: ~/Library/Application Support/NEXUS Launcher.

Внутри этих каталогов .launcher-updates хранит проверенные версии, кэш и журналы. Не редактируйте active.json, highest-package.json и transition.json и не удаляйте слоты во время работы. Предыдущие версии сохраняются; для полных пакетов требуется дополнительное свободное место.

macOS: подпись NEXUS не заменяет Apple Developer ID или notarization. Карантин сохраняется при переносе существующего bundle и добавляется скачанным обновлениям. Перед активацией выполняется системная проверка запуска. Если macOS не разрешает новую версию, показывается OS_APPROVAL_REQUIRED, а ранее проверенная версия остаётся выбранной. Может потребоваться штатное ручное подтверждение macOS или ручная установка; отключение Gatekeeper и снятие quarantine не выполняются и не требуются этим кодом. Гарантия полностью беззапросного запуска на Mac без Developer ID не заявляется.

Windows: подпись манифеста NEXUS не является Authenticode; Smart App Control может заблокировать новый EXE/DLL. Настройки защиты не изменяются.

Базовые среды: Linux x64 / Ubuntu 24.04 и macOS 15+ / Apple Silicon. Все дистрибутивы Linux, ARM Linux и Intel Mac не квалифицированы. Реальный вход в Minecraft, сеть тестера без VPN и проверка загруженного приложения через Gatekeeper на личном Mac — отдельные проверки.
