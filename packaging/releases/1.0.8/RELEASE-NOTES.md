# NEXUS Launcher 1.0.8 — Cross-platform Updates Beta

Это бета-тест. Сообщайте об ошибках на teentitans645@gmail.com, прикладывая версию, ОС, шаги воспроизведения и диагностический лог без паролей, кодов и токенов.

- Windows managed: сохранено обновление через подписанный GitHub-манифест.
- Linux x64 и macOS Apple Silicon: добавлены отдельные подписанные ленты, проверка файлов и внутренних ссылок, подготовка неактивной версии и переключение после готовности настоящего интерфейса.
- Исходная версия сохраняется. Неопределённый результат не считается успешным обновлением.
- macOS quarantine сохраняется; отказ системы не обходится и не выдаётся за успешную установку.

## Установка

Для Linux/macOS 1.0.7 и старше нужно один раз вручную установить полный пакет 1.0.8. Старые бинарники не содержат нового updater. После появления окна исходной версии фоновая подготовка требует подключения к GitHub; при ошибке можно продолжать пользоваться исходной версией. Подробности — AUTOUPDATE.md.

Поддерживаемые целевые сборки: Windows x64, Ubuntu 24.04 x64, macOS Apple Silicon (arm64, CI macOS 15). Другие дистрибутивы Linux и Intel Mac этим выпуском не квалифицированы.

EXE пока не имеет платной подписи Windows. Результат Microsoft для прежнего файла не гарантирует допуск нового файла. macOS Developer ID / notarization отсутствуют; автоматический допуск Gatekeeper не гарантирован. Настройки защиты менять не требуется и установщик их не меняет.

Проверки Linux/macOS используют настоящий упакованный интерфейс и синтетическое обновление 1.0.8→1.0.9 с временным тестовым ключом. Такая 1.0.9 не является публичным выпуском. Эти проверки не доказывают запуск Minecraft, вход реального аккаунта, production trust или NEXUS C₂ readiness.
