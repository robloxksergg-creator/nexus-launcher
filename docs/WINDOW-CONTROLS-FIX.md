# Window controls and Studio marker audit — v28

The three controls in the actual application frame are TitleBar.minimize, maximize and close_button from nexus_launcher/nexus_platform/window_chrome.py, installed by PrototypeHost and inherited by DesignHost. They minimize NEXUS, maximize/restore the same window, and close NEXUS through the existing close event (including the existing leave checks). They are not obsolete Studio panel controls. Existing click handlers were connected, not stubs; Academy and the browser are below the native title bar.

The native resize overlays were raised over all four edges/corners. The top six pixels of every title button and the right six pixels of Close were therefore owned by ResizeEdge rather than the control. Hit regions now stop before the title-button cluster; right-edge resizing begins below the title bar and the top-right corner yields to Close. Other edges retain native system resize behavior. Real QApplication.widgetAt tests cover centers and corner pixels, with actual minimize/maximize/restore/close and Enter/Space activation.

Window controls used Unicode font glyphs, native QPushButton drawing and inherited stylesheet padding. The fix reuses NexusButton keyboard/focus behavior and draws small semantic vector icons, pressed/hover surfaces and an accent rectangular keyboard focus indicator. It resets title-button padding/minimum content metrics. There are no global focus suppressions or blanket circle selectors. Default Qt glyph/focus painting is no longer used by these buttons.

Studio's current resize grips were traced to the old renderCanvas wrapper and workspace.css. They already have an accent square override. They are retained, not hidden wholesale: real pointer drag/resize tests verify geometry changes; visible grips are non-white and square; locking removes them and clearing selection hides them. No separate unexpected circle element was reproduced in the Studio DOM; this audit does not claim that every user-observed dot was proven to originate in one specific rule.
